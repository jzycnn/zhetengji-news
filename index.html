To Do grew out of "Wunderlist," the popular task manager whose developer, 6Wunderkinder, Microsoft acquired in 2015. Microsoft introduced To Do in April 2017 as Wunderlist's intended successor, built by the same team. Initially available as a preview for iPhone, Android, Windows, and the web, it added a My Day view that suggested tasks to focus on. Microsoft said it would keep Wunderlist running until its key features were available in the new app. A native Mac app followed in June 2019, bringing offline access, shared lists, flagged Outlook emails, and a compact window for viewing tasks alongside other apps.
